# LinknRun Marketing Site — V1

Fast, light-mode static marketing site for LinknRun.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Inter + Unbounded

## Run
Open `index.html` directly, or serve the folder with any static server.

## Replace later
- Placeholder runner/gym artwork in `index.html`/`styles.css`
- App UI mockup in the showcase section
- Google Play/App Store URLs in `index.html`
- Logo with the real LinknRun logo
- Real photography and app screenshots

The download buttons are intentionally disabled until real store links are supplied.
